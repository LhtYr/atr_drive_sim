# 无感起动【带载校核】工况（criterion 4）：在 config/sensorless_start.txt 无供气空载基础上施加负载，
# 验证 I/F + STSMO + PLL 起动全程不失步、I_f 裕度充足。
#
# ============================ 为何用粘性轴负载代表"泵负载" ============================
# 本模型中两类"负载"在【起动段】均无法提供有效阻力矩，经实测确认：
#  · 涡轮：T_turb=eta_mech·power/max(ω,ω_floor) 仅在 p_plenum>p_downstream 时产生【驱动】转矩(≥0)，
#    结构上不能抵抗转动；无供气(m_dot=0、容腔=背压)时 T_turb≡0。故涡轮无法作起动负载。
#  · 泵水力转矩：T_pump=rho·g·Q·H/eta/ω，扬程 H 与流量包线均 ∝ n²，且效率拟合 eta(Q/n) 仅在
#    很窄的 x=Q/n 带内为正（带外视为无有效工况点、T_pump=0）。固定背压只能让泵在某个 ~2× 转速窗口
#    内短暂出力（如 50 m 扬程对应约 7500–14300 rpm），窗口外 T_pump≡0；I/F 段(0–2000 rpm，
#    关死扬程仅 h_nn·n²≈3.6 m≈35 kPa)泵水力转矩可忽略。故固定背压的泵水力负载无法覆盖起动全程。
# 因此带载校核以【泵/风阻折算到轴上的粘性负载】shaft.b_pump 实现：T_load=b_pump·ω 全程存在
# （含最易失步的 I/F 段），是考验 I_f 拖载裕度的有效且可控方式（任务书允许"给出参数调整说明"）。
#
# ============================ 负载整定与 I_f 裕度 ============================
#  I_f=60 A -> 最大电磁转矩 K=(3/2)·p·ψ_f·I_f≈10.71 N·m（δ=0 失步边界）。
#  b_pump=0.005 N·m·s（叠加默认 b_motor+b_turb=0.0048 -> b_total≈0.0098）：
#   · I/F 切换点 2000 rpm(209 rad/s)：阻力矩≈b_total·ω≈2.05 N·m，加斜坡惯量 J·α≈0.54 N·m，
#     合计≈2.6 N·m = K 的 ~24% -> cosδ0≈0.24、δ0≈−76°、经典功角 δ'=δ0+90°≈14°，远离失步 90°。
#     实测 I/F：δ∈[−90,−75.1]、δ'∈[0,14.9]、Tem≤2.75 N·m、转速单调、无后仰、无失步。
#   · 20000 rpm(2094 rad/s)：阻力矩≈20.5 N·m -> 稳态 iq≈115 A，仍收敛 20000 rpm、
#     |theta_err|≈1.3°、ω̂ 跟踪误差≈0.05%。电压可行（E≈249 V < SVPWM 线性上限 311 V）。
#  若需更大负载而 I_f 裕度不足（δ0 逼近 0、δ'→90° 失步），应【增大 I_f】（--if-current 或
#  sensorless.if.i_start）以抬高 K=(3/2)p·ψ_f·I_f，而非放宽判据；同时须保证 I_f<2×稳态 iq
#  以满足切换电流冲击判据（必要时同步抬高切换转速 ω_switch 降低稳态 iq）。

# --- 无供气空载基础（同 sensorless_start.txt，消除涡轮容腔吹除瞬态）---
turbine.p_plenum_init     = 100000.0
turbine.p_downstream_init = 100000.0
boundary.turb_p_in   = 100000.0
boundary.turb_p_out  = 100000.0
boundary.turb_T_in   = 1000.0
boundary.turb_m_dot  = 0.0

# --- 泵/风阻折算粘性轴负载（全程含 I/F 段，考验 I_f 裕度）---
shaft.b_pump = 0.005
